# Demo photos

Drop your own images here (JPG, PNG, WebP). The Media blade's Pictures
screen (DESIGN.md §6.13) opens the Computer source, whose picture browser
(§6.13.1) shows them in its 3×3 grid, and whose picture viewer (§6.13.2)
plays them as a slideshow. Then list each file in
`app/blade-dashboard-mockups/_components/pictures.ts` so the grid knows its
name; unlisted slots stay as striped placeholders, and the grid shows at
most the first nine.
